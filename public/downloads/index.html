🚀 Deploy ulang cepat (ringkasan)

  1. Unduh ZIP Lengkap → ekstrak → push ke repositori GitHub Anda.
  2. Vercel → New Project → Import → set env NEXT_PUBLIC_SITE_URL = https://pusatgeely.web.id → Deploy.
  3. Settings → Domains → sambungkan pusatgeely.web.id (DNS: A 76.76.21.21 / CNAME cname.vercel-dns.com).
  4. Cek /api/seo-status → pastikan host = canonical, sitemap = 59 URL.
  5. Google Search Console (property https://pusatgeely.web.id) → Sitemaps → submit sitemap.xml.
